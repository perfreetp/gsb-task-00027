# 跨校区车辆与围栏管控中台

面向连锁驾校集团总部、校区校长/调度员与教练的一体化车辆调度、电子围栏、学时归属、成本分摊和风险告警控制台。

## 启动

```bash
npm install
npm run dev
```

质量检查：

```bash
npm test
npm run build
```

## 功能范围

- 城市级 Three.js 三维沙盘：主干道、校区、考点、加油站、维修点、实时车辆位置、围栏和调车路线。
- 校区精模：进入校区后查看库位占用、训练区域和本地围栏。
- 调车申请：选车、目的地、预计到达、随车教练、优先级，支持目的地校长与总部审批。
- 在途监控：偏航、长时停留、超时未达等异常挂接到同一张调车单。
- 跨区学时：按科目、车型、日/夜时段配置学员、车属校区、训练校区归属比例。
- 成本分摊：油费、过路费、车辆折旧按多条件规则分摊并生成校区对账视图。
- 围栏治理：总部模板、校区套用、本地微调、差异原因和安全类改动总部确认。
- 车辆经营：车辆档案、年检保险保养、终端在线状态、新增/淘汰额度审批、利用率排行。
- 集团视图：告警总览下钻、双校区同时段三维回放、月结报表、CSV 审计导出。
- 多角色：总部全量，校区按本校过滤，教练仅能看到本人车辆和相关告警。

## 核心模块

- `src/domain/transfers.ts`：调车状态机、幂等创建、同车队列、撤回/驳回/超时释放、换车回滚、在途轨迹。
- `src/domain/rules.ts`：科目/车型/时段/生效日期规则解析，学时与成本试算结果携带版本快照。
- `src/domain/fences.ts`：点位命中、围栏面积、限速与禁入区安全影响评估。
- `src/scene/CityScene.ts`：Three.js 场景、图层、拾取、校区聚焦和路线相机漫游。
- `src/domain/store.tsx`：角色可见范围、页面操作、审计日志统一入口。
- `src/domain/*.test.ts`：核心并发与历史规则回归测试。

## 三项难啃点的处理

1. **多条件分摊可回溯**：规则按明确条件优先、`ALL` 兜底、生效日期和版本裁决；每次试算结果返回命中规则、生效日期、版本和输入快照。
2. **审批链可回滚不重复**：所有单据使用 `idempotencyKey` 去重；撤回、驳回、超时关闭进入终态并释放车辆锁；事件链记录每次状态变化。
3. **一车两派唯一裁决**：每辆车同时只允许一个锁定单据，其他申请进入同车队列，按优先级、提交时间排队；锁释放后仅队首自动进入审批，换车会释放旧车并对新车重新裁决。
