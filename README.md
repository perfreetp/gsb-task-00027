# 跨校区车辆与围栏管控中台

面向连锁驾校集团总部、校区校长与调度员的三维车辆调度、围栏安全、跨区学时与成本分摊工作台。

## 快速运行

```bash
npm install
npm run dev
```

默认访问 `http://localhost:5173`。生产构建：

```bash
npm run build
npm run preview
```

## 功能覆盖

- 城市级 Three.js 沙盘：主干道、校区、考点、加油站、维修点、实时车辆；支持旋转缩放、对象拾取、校区聚焦、图层开关和沿调车路线漫游。
- 校区精模：库位、训练区、限速区、禁入区、接待区的容量与占用态势；从沙盘可直接进入。
- 跨校区调车：选车、目的地、ETA、随车教练、原因和优先级；目的地校长确认后总部放行。
- 冲突裁决：同一车辆多个申请按优先级和提交时间排队，仅队首且双审通过的申请可发车。
- 幂等与回滚：重复审批、重复发车、重复到达成本入账均拦截；撤回、驳回、超时和换车会关闭原单并释放队列。
- 在途监控：偏航、超时未达、长时间停留、越界、离线、超速告警；集团总览可按校区下钻处理。
- 跨区学时：按科目、车型、时段多条件匹配规则；学员学时独立 100% 归属，车属/训练校区拆分经营归属。
- 成本分摊：油费、过路费、车辆折旧按车属、训练/申请校区比例生成校区对账单，支持 CSV 导出。
- 规则版本：新规则发布为新版本，历史训练与调车成本锁定当时版本，后续调整不覆盖历史结果。
- 围栏模板：总部维护标准模板，校区套用后可本地微调，但必须填写差异原因并经总部审批。
- 安全变更审批：禁入区扩大、限速下调、封场时间调整等影响安全或工时的变更集中审批。
- 车辆资产：归属、当前校区、年检、保险、保养、定位终端、教练绑定和在线状态。
- 车辆额度：新增与淘汰申请由总部统一审批和分配额度。
- 运营分析：车辆利用率排行、告警横向对比、双校区同一时段三维回放、月结报表。
- 角色范围：总部看全部，校区校长看本校，教练只看本人车辆和本人调车任务。
- 审计：围栏、规则、分摊比例、审批和车辆额度均保存前后快照，可筛选并导出 CSV。

## 关键实现

- `src/engine.ts`：审批状态机、排队裁决、幂等校验、换车/撤回/超时回滚、规则匹配、学时和成本计算。
- `src/ThreeCity.tsx`：城市沙盘、图层、车辆/校区拾取、镜头动画与路线漫游。
- `src/access.ts`：总部、校长、教练三类角色的数据可见范围。
- `src/pages/`：各业务工作台页面。
- `src/data.ts`：可直接演示的校区、车辆、调车、告警、规则、围栏和审计样例数据。

## 说明

该项目是无需后端的高保真前端原型，状态保存在浏览器内存中，刷新后恢复为演示数据。后续接入真实系统时，可将 `src/engine.ts` 的纯函数迁移到服务端事务服务，并通过 WebSocket 推送车辆位置和告警。
